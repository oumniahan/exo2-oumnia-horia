# Exercice 2 - Routing Angular

Projet fait par Oumnia et Horia.

Site "CinéClub" en Angular avec Bootstrap.

## Pages

- `/accueil` : un mème au milieu de la page
- `/liste` : nos 5 films préférés, au clic on affiche le titre et l'affiche
- `/gestion` : le dernier formulaire de contact envoyé (sinon 404)
- `/contact` : le formulaire de contact (bouton dans le footer)

Les URL vides ou qui n'existent pas redirigent vers l'accueil.

## Lancer le projet

```bash
npm install
ng serve
```

Puis aller sur http://localhost:4200
